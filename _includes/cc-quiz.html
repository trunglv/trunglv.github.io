Quick quiz: how well do you know the mechanics? 1 / 6

1. Resuming a session from yesterday. Which is true?

The transcript on disk costs nothing to keep, but resuming re-sends everything. If the cache has expired, the first request pays to write it again.

2. Roughly how does the cache price compare with normal input, for a read within the lifetime?

Cache reads are billed at 0.1x base input (0.05x on Opus 5.5 and Sonnet 5.5, 0.025x on Fable 5.1 and Mythos 5.1). Writing to the cache costs 1.25x once.

3. Where does a subdirectory's CLAUDE.md load?

Root and parent CLAUDE.md files load at launch. Files in subdirectories load on demand, which is why a large project can keep one file per system.

4. You are in the middle of a bug, and an unrelated question comes up. Which keeps the history clean?

/btw answers without adding the exchange to the conversation. Compacting still carries a summary of the unrelated question forward.

5. An image is 1000 × 1000 pixels, on a standard-tier model. Roughly how many tokens?

An image costs ⌈width/28⌉ × ⌈height/28⌉ tokens. 1000 / 28 rounds up to 36, so 36 × 36 = 1,296 tokens.

6. Which of these is billed as output tokens?

Thinking tokens are generated by the model, so they are billed at the output price, which is several times the input price. In this post's session they were about 29% of output.
