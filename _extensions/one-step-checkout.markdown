### Overview

OneStepCheckout simplifies the Magento 1 checkout process, combining the usual multi-step flow into a single page.

### Support

Free and open-source. Contributions are welcome — open an issue or a pull request on the [GitHub repository](https://github.com/trunglv/OneStepCheckout) to help improve it.
