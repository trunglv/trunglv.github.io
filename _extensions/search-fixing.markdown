### Overview

This is a quick fix for an issue where Magento 2's search functionality breaks — raising a `number_format_exception` — when one or more searchable attributes are of the Decimal data type.

### Support

Free and open-source. See the [GitHub repository](https://github.com/trunglv/magento2_search_fixing) for the fix and installation details.
